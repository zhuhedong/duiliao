# 对料 App 原型逐页逐功能审查报告

审查范围：`app-design/` 下 23 个移动端 HTML 页面、1 个网页端共识榜、公共样式与原型交互脚本。

## 本轮已修正

### 1. 认证与敏感操作

- 登录页不再通过静态链接直接跳转工作台，改为表单校验；空账号/密码会提示，填入后明确提示“演示原型：未连接身份服务，未登录”。
- 登录页增加账号/密码的 `label` 关联、`autocomplete`、密码显示/隐藏按钮。
- 个人中心的密码修改增加当前密码、新密码、确认密码、长度校验和一致性校验；原型不会伪造修改成功。
- API Key 不再放置伪造的 `sk-...` 值，改为“演示不保存”的输入提示。

### 2. 导航与数据一致性

- 开奖列表的 2026276、2026275、2026274、2026273 分别进入带 `period` 参数的详情页，不再全部打开同一个期号。
- 开奖详情根据期号更新标题、开奖时间、号码、生肖、属性、命中统计和采集统计。
- 波色、生肖、五行、大小、头尾数据按 `frontend/src/lib/lotteryAttr.ts` 的 2026 口径复核；特别修正了 26 的五行/大小和各期生肖展示。
- 共识移动端、共识网页端修正重复对象属性、错误命中标记、波色计算、票数分母和样例命中率。
- 玩法目录修正未定义的 `--info-subtle` 变量。
- 设计总览保持 23 屏，保留“号码分析”和独立的“跳码助手”。

### 3. 交互与原型边界

- 新增 [prototype.js](assets/prototype.js)，统一提供：
  - demo toast 反馈；
  - 分段按钮状态切换；
  - switch 的 `role="switch"`、键盘操作和 `aria-checked`；
  - 筛选输入的本地样例过滤；
  - 空 hash 动作的演示反馈；
  - AI 研判的空指令拦截；
  - 密码修改表单校验；
  - 动态生成按钮的安全默认 `type="button"`。
- 15 个原本 `href="#"` 的假链接改为显式演示按钮，避免点击后静默跳转顶部。
- AI 研判、AI 报告、数据源、开奖管理、监控、评级、设置、共识页面增加“样例/非实时/需连接后端”等提示，避免把静态数据伪装成实时状态。
- 所有 HTML 按钮补齐明确 `type`，减少表单误提交风险。

### 4. 可访问性与移动布局

- 公共样式增加 `:focus-visible` 焦点样式。
- 增加 `prefers-reduced-motion: reduce` 降低动效偏好用户的动画干扰。
- 为 segmented/pressed 状态补充基础 ARIA 状态样式。
- 360px 以下屏幕收紧顶栏、隐藏次要状态胶囊、KPI 改为两列，降低窄屏溢出风险。

## 需要后端接入的功能

以下动作目前只做了安全的原型反馈，不能视为已经执行：

- 登录、退出登录、密码修改、忘记密码、初始化管理员；
- 数据源测试运行、脚本录入、定时调度、上游巡检、缺期确认；
- 开奖同步、手动对奖、同步日志、自动开奖任务；
- 记录保存、删除、复制格式、结算和统计；
- 评级矩阵计算、导出评级；
- AI 数据抓取、研判任务、报告生成、原始 HTML、导出/分享；
- 共识查询、来源证据下钻、冻结快照和官方开奖核验；
- AI 配置、数据库配置、缓存清理和表迁移。

## 验证结果

- HTML 结构、重复 ID、本地链接、本地脚本引用：通过，0 个错误。
- 所有按钮均有明确 `type`：通过。
- 内联脚本与公共 `prototype.js`：使用 macOS JavaScriptCore `osascript` 做 `new Function` 语法检查，29 个脚本单元通过，0 个语法错误。
- 开奖示例的波色和生肖：按 2026 属性集合复核，通过。
- 跳码助手功能覆盖检查：正选/反选、生肖、家野、五行、波色单双、头尾尾数、复制/清空共 12 项全部存在。
- `git diff --check -- app-design`：通过。

## 当前限制

当前工作区没有进行浏览器级点击截图回归；因此 CSS 像素级视觉差异、不同浏览器的真实渲染和系统剪贴板权限仍需在浏览器或设备上做最后一轮验收。原型中的样例数据也不能替代正式接口返回的数据、快照时间和证据链接。
